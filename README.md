# TGN
My own reproduction of the [TGN Paper](https://arxiv.org/abs/2006.10637)

# Why this ? 

While working at Dragonfly, I worked a document retrieval system based on graph encoding of our entreprise information. This led me to discover temporal graphs as a concept. 
I hope that by modeling LLM agent tool use as a temporal graph we can achieve better retrieval metrics in our system.

**Temporal Graph Networks for Deep Learning on Dynamic Graphs** is a seminal paper in the temporal graph field and I wanted to do deep dive in its architecture.
